# Sistema 05: Web Corporativa de Alta Conversión

## Propósito
Landing page y sitio corporativo orientado a maximizar el porcentaje de conversión de visitantes en clientes calificados (leads) para empresas de servicios y tecnología.

## Módulos y Estado Reactivo
- `WebCorporativaApp.jsx`:
  - Simulador reactivo de Retorno de Inversión (ROI): compara la tasa estándar de mercado (1.2%) vs el estándar optimizado por RED (4.8%).
  - Formulario de calificación de prospectos con captura de requerimientos.
  - Métricas de velocidad de carga y rendimiento Google PageSpeed (99/100).
  - Integración directa para envío de requerimientos a WhatsApp.

## Edición Rápida
- Fórmulas de conversión y WhatsApp en `CONVERSION_CONFIG`.
