# Sistema 02: Software para Logística y Transporte B2B

## Propósito
Sistema diseñado para empresas de flotas de camiones, distribución pesada y transporte comercial de media y larga distancia.

## Módulos Operativos
- `LogisticaApp.jsx`:
  - Telemetría en tiempo real de 25 unidades de flota (estado: En Ruta, En Espera, Taller).
  - Calculador dinámico de viáticos y consumo de combustible por ruteo (km x rendimiento).
  - Tablero de alertas mecánicas preventivas (neumáticos, service de 20.000 km, VTV).
  - Registro de choferes asignados con licencia y contacto rápido.

## Edición Rápida
- Costo base de combustible y rutas configurables en `FLEET_CONFIG`.
