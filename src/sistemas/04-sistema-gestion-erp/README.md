# Sistema 04: Sistema de Gestión ERP & CRM a Medida

## Propósito
Demostración de software administrativo y panel de control personalizado para empresas que superaron la capacidad de Excel y requieren centralización, trazabilidad y cero error humano.

## Módulos y Estado Reactivo
- `GestionApp.jsx`:
  - Panel superior de métricas financieras (Facturación, Cobranzas al día, Clientes activos).
  - Listado y búsqueda dinámica de clientes y comprobantes.
  - Formulario de alta para registrar nuevas facturas o movimientos.
  - Simulación de tubería de datos con PostgreSQL y Redis (tiempos de respuesta inferiores a 15ms).

## Edición Rápida
