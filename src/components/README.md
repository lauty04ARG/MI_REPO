# Componentes Principales - RED Soluciones Digitales

Mapa de contexto rápido para agentes IA y desarrolladores.

## Índice de Componentes
- `Navbar.jsx`: Barra superior con logo, enlaces de navegación responsive, menú hamburguesa y botón de cotización directa.
- `Hero.jsx`: Portada con badge de precisión, título impactante con subrayado rojo `#DA0037`, botones de acción y stack técnico.
- `Services.jsx`: 4 tarjetas de soluciones especializadas (Web, IA, Sistemas, Logística) con métricas de inversión base y tiempo de desarrollo.
- `PortfolioGrid.jsx`: Galería interactiva con mini-interfaces visuales simuladas (sin `<img>` vacías) y disparador de apps completas.
- `WebTemplatesGrid.jsx`: Grilla de presentación de los 4 bocetos web por industria con acceso a pantalla completa.
- `Authority.jsx`: Credenciales de ingeniería (UTN, Cambridge) y tarjeta destacada con 0% de fricción operativa.
- `QuoteCalculator.jsx`: Cotizador en vivo con desglose por módulos, velocidad de entrega y botón de WhatsApp dinámico.
- `Footer.jsx`: Cierre de conversión con agenda de consultoría y enlaces de contacto directo.
