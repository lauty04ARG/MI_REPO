# Bocetos Web Estáticos &bull; RED Soluciones Digitales

Colección de 5 páginas web estáticas maquetadas con Tailwind CSS para rubros comerciales específicos. Cada una adopta una paleta y psicología visual adaptada a su nicho.

## Bocetos Incluidos (5)
1. `BocetoInmobiliaria.jsx`: Real Estate minimalista de lujo, casas de arquitectura de autor y dossiers privados.
2. `BocetoEstudioJuridico.jsx`: Sobriedad corporativa para estudios de abogados, compliance y canal confidencial.
3. `BocetoGastronomia.jsx`: Cafetería de especialidad y restó contemporáneo con carta de origen y reserva de mesas.
4. `BocetoAgroIndustrial.jsx`: Ingeniería pesada, tolvas y maquinaria agrícola B2B con fichas técnicas descargables.
5. `BocetoClinicaEstetica.jsx`: Medicina estética y wellness VIP con comparador interactivo de antes/después y reserva concierge.
